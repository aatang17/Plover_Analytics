# Pin the web stack exactly. `fastapi>=0.110,<1` let the container build a
# version the laptop had never run, and on 2026-09-05 that difference rejected
# all nineteen dataset manifests in production while every test passed locally:
# the route table looked different inside the image. The registry no longer
# depends on how routes are represented, but the drift itself is the defect —
# the same one the DuckDB pin below exists for. What is tested is what ships.
#
# These four move together; upgrade them together, deliberately, and run the
# suite plus `python -m app.registry --check` before deploying.
fastapi==0.128.8
starlette==0.49.3
pydantic==2.13.4
uvicorn[standard]==0.39.0
# Pin DuckDB: INSERT OR REPLACE semantics around foreign keys changed between
# 1.4 and 1.5, and an unpinned install made production diverge from local.
duckdb>=1.4,<1.6
# optional: only needed for /api/v1/{dataset}/ask — the rest of the app runs
# without it, and the ask box stays hidden when ASK_ENABLED is unset/false
# or when a provider key is absent.
# `openai` is the client library for both providers this app supports:
# DeepSeek (set DEEPSEEK_API_KEY) or OpenAI directly (set OPENAI_API_KEY) —
# DeepSeek's API matches OpenAI's request/response shape. Override the model
# with LLM_MODEL and, for any other OpenAI-compatible endpoint, LLM_BASE_URL.
openai>=1.40,<2
# The nightly equity refresh reads the EDINET archive out of the S3-compatible
# bucket the capture jobs write to. Without EDINET_S3_BUCKET set, the refresh
# skips itself and nothing here is imported.
boto3>=1.34,<2
# Crops the blank border off an uploaded company logo as it is served
# (app/logo_trim.py); without it a logo is served exactly as uploaded.
pillow==11.3.0
